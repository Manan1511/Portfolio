# Original Manan character artwork

Created with the built-in imagegen tool, using the user's supplied photos as private likeness references. Photos remain outside the repository. These are original character assets, with genuine alpha transparency and no furniture or scene props.

## Saved assets

- `manan-master.png` — coherent seated design reference, 1254×1254.
- `manan-seated.png` — shared typing/dialogue sheet, 1774×887; four typing poses on the upper row, four speech expressions on the lower row.
- `manan-poses.png` — standing, standing blink, thumbs-up and portrait, 1254×1254.

`src/character/manan.ts` supplies whole-frame source rectangles, integer target registration, anchors and timing. Images are sampled into a native 120×120 canvas without smoothing. The full-body character is about 100 native pixels tall. The original generated PNGs are retained; the renderer draws complete frames without compositing body parts.

## Generation prompt set

The master and pose sheet are final assets. A typing-sheet generation served as an intermediate reference for the final shared seated sheet; that discarded intermediate is not shipped.
